# Journal 用户指南

> 给**使用者**看的一页。开发/架构说明见根 [`README.md`](../README.md) 与 [`.trellis/spec/`](../.trellis/spec/)。

## 它是什么

一个 Chrome **侧边栏扩展**：把「今天干了什么」记成卡片，落到日程时间线上，并用热力图回看坚持情况。

三句话定位：

1. **贴在工作流里** —— 不用为一天只用一次的功能装一个软件，点开侧边栏就能记。
2. **数据在你自己手里** —— 本地 SQLite 权威存储，可选同步到自己选定的介质（文件夹 / WebDAV / GitHub 私有仓库）。
3. **AI 也能读写同一份数据** —— 本机 host 暴露 REST，Claude Code / Codex 等 agent 可以直接把今天做的事写进你的日志。

## 安装

1. 打开 `chrome://extensions` → 打开右上角 **Developer mode**
2. 点 **Load unpacked** → 选择仓库里的 `extension/` 目录
3. 点浏览器工具栏的 Journal 图标 → 侧边栏打开

**host 服务（可选，但推荐）**：host 是权威数据库。不启动 host 也能看（用离线缓存），
但**改动无法保存**。

```bash
node host/server.js        # 启动，默认 127.0.0.1:8766
```

侧栏顶部会显示一个状态灯：🟢 已连接 / 🔴 未连接。未连接时页面顶部会出现一条
**持久提示条**，点上面的「启动服务」按钮即可拉起。

## 记录今天（60 秒上手）

| 想做什么 | 怎么做 |
|---|---|
| 记一条 | 点时间线右上角 **＋**（或卡片池的「＋ 新卡片」） |
| 只填标题就行 | 可以。标题和内容**至少填一个**即可保存 |
| 排个时间 | 编辑器里填「开始/结束」，或直接在时间线上**拖出一段** |
| 改时间 | 在时间线上**拖动卡片**整体移动；拖**底边**改时长（15 分钟吸附） |
| 找东西 | 卡片池顶部**搜索框**（标题/内容/标签/项目/自定义属性） |
| 看某天 | 点日历某天，或用时间线的 `‹ ›` 翻页 |
| 回看坚持 | 左侧「🔥 打卡」热力图 + 连续天数 |
| 别忘事 | 卡片填了「开始时间」就会到点弹**系统通知**（本机计算、不联网；设置页可关） |

**卡片字段**：标题、内容、图标（点卡片头部方块选 emoji）、状态（纯记录/未开始/进行中/已完成，
也可自定义文字）、进度、优先级、排程、日期、标签、项目、以及任意**自定义属性**。

**快捷操作**：`Esc` 关闭编辑器（有未保存改动会先问），`⌘/Ctrl + ⏎` 保存。

**到点提醒**：只要卡片有开始时间且当天未完成，到点会弹浏览器通知；同一张卡当天只提醒一次。
关掉提醒：设置页「数据」区 → 取消勾选「到点提醒」。

## 三种主视图

| 视图 | 用途 |
|---|---|
| 📅 月历 | 一眼看整月分布，点某天跳转 |
| 📆 周历 | 看一周的并行安排，支持拖动框选建卡 |
| ⏱ 日程 | 一天的时间线：拖拽改时间、拖边改时长、并行事件自动分道、当前时刻指示线 |

**卡片池**是左侧的筛选面板：按状态 / 标签 / 项目筛选，可把当前筛选存成**命名视图**，
支持卡片/列表两种布局，也能从**模板**一键建卡。

## 数据在哪 / 怎么备份

| 东西 | 位置 |
|---|---|
| **权威数据** | `host/data/journal.db`（SQLite） |
| 扩展离线缓存 | `chrome.storage.local`（镜像，仅供 host 离线时查看） |
| AI / 同步凭据 | `host/data/config.json`（**不会**上传任何服务器） |

**导出全部数据**：设置页 → 「数据与同步」→
- **⬇️ 导出全部数据（JSON）** —— 从 host 权威库导出，可用于备份或喂给 AI
- **📄 导出为 Markdown** —— 人类可读的按天归档

> 导出来自 **host 权威库**，不是扩展缓存副本 —— 设置页以前只能导出镜像，可能落后。

**删除可以撤销**：删卡片后 6 秒内点提示条上的「撤销」即可恢复。

## 多端同步（可选）

把卡片写到共享介质，各设备独立同步后自动收敛：

| Provider | 介质 | 适合 |
|---|---|---|
| `local` | 本地/云盘文件夹 | 最简；目录放在 iCloud / OneDrive / 坚果云同步盘即可跨机 |
| `webdav` | WebDAV 服务器 | 坚果云、Nextcloud 等 |
| `github` | GitHub 私有仓库 | 建议用独立分支 `sync-data` |

规则：**逐卡 LWW**（`updatedAt` 新者胜）+ **删除墓碑**（删除永远传播、不会复活）。

触发方式：设置页「☁️ 立即同步」、`POST /api/sync/now`、或 `node host/cli.mjs sync`。

## 离线时会怎样

| 场景 | 行为 |
|---|---|
| host 未启动 | 顶部持久提示条「本机服务未连接，改动不会保存」；仍可**查看**上次缓存 |
| 保存卡片 | 明确报错 toast，编辑器**保留你输入的内容**，不会静默丢弃 |
| 保存模板 / 命名视图 / 属性库 | 明确报错；**不会**把已有数据覆盖成空 |
| AI 功能 | 静默降级到本地规则推断（不打断记录） |

> 之前的版本在 host 离线时会「弹已保存但实际没存」，甚至把模板覆盖成一条 —— 已修复。

## 常见问题

**Q：一定要装 Node / 跑 host 吗？**
不装也能用来看，但保存需要 host。host 是零依赖的（只用 Node 内置模块），`node host/server.js` 即可。

**Q：数据会上传到云端吗？**
不会。host 只监听 `127.0.0.1`；同步是你自己配置的介质，凭据只存在本机。

**Q：能和其他 App 一起用吗？**
可以。`GET /api/export?format=markdown` 是纯文本，`GET /api/cards?q=` 支持子串检索，agent 也可以直接调 REST 写入。

**Q：误删了怎么办？**
删除后 6 秒内点「撤销」。超过 6 秒，可以从 `host/data/` 下的备份或同步介质中恢复（同步保留删除墓碑，需从另一端的快照取回）。
