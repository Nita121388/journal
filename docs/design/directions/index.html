Journal 视觉方向 · P0 样张

同一屏内容，三种视觉语言 · 真实数据 · 亮/暗 · 三宽度

方向 A · Paper Desk 推荐

抄了：Inkra 的「整页一张纸 + 墨线分隔、无阴影」，BoardUI 的尺寸标尺与卡片三段式。 牺牲：极简的工具感——层级全靠明度与墨线，屏幕素质差时对比会偏软。

方向 B · Quiet Desk 备选

抄了：BoardUI 字面（纯白面板 / 蓝主色 / 大圆角 / 极弱投影）+ HeroUI 状态矩阵。 牺牲：产品记忆点——和任何 SaaS 后台长得一样，三个月后仍会觉得「普通」。

方向 C · Hand-drawn Desk 激进

抄了：Looseleaf/Inkra 的墨边纸面 + 贴纸 + 手写标题，PlopUI 的按下位移。 牺牲：数据密度下的可读性与长期维护成本——装饰元素一多就会回到「吵」。

切换宽度只改变 iframe 宽度（模拟真实侧栏 320–500px）。截图存档见 shots/：<direction>-<width>-<theme>.png。 这些是目标态样张，不是可运行代码；选定方向后才落 token 与组件。
