# 视觉方向样张（P0）

打开 **[index.html](index.html)** 对比三个方向（可切换 320/400/500 宽度与亮/暗）。
每份样张都是**自包含单文件**，可直接用浏览器打开：

| 文件 | 方向 | 一句话 |
|---|---|---|
| `a-paper-desk.html` | Paper Desk（推荐） | 暖纸底 + 墨线分隔 + 墨块主按钮；绿只作数据色 |
| `b-quiet-desk.html` | Quiet Desk | 纯白/石板灰 + 蓝主色 + 大圆角 + 极弱投影（BoardUI 字面） |
| `c-handdrawn-desk.html` | Hand-drawn Desk | 奶油纸 + 抖动墨边 + 楷体标题 + 高亮马克笔 |

`shots/` 下有 3 方向 × 320/400/500 × 亮/暗 = 18 张截图，命名 `<direction>-<width>-<theme>.png`。

## 参考源实测摘录

调研方式：2026-11-08 用 Playwright 实际打开各站首页并截图，提取其排版/材质/控件语言，
不是根据描述臆测。结论（详见主任务 `prd.md` 的判定表）：

| 源 | 抄 | 不抄 |
|---|---|---|
| **BoardUI** | 间距标尺、卡片三段式（标题/元信息/右对齐数值）、三档控件高度、极弱描边+大圆角、自建 select | React/Aria/TanStack 依赖；蓝色主色与"日志"气质不符 |
| **HeroUI** | 组件四态矩阵、chip/badge 的克制配色 | 只是组件清单，无版式主张 |
| **Inkra** | **整页一张纸**：墨线分隔替代灰盒、无阴影、暖白+墨黑 | 楷体正文在 11px 数据界面不可读；仅浅色 |
| **Looseleaf** | 纸纹、胶带、图钉、便利贴——**限量签名** | 全站手写字体+手绘边框在数据密集界面噪音爆炸 |
| **Solid Glass** | 暗色烟熏 pane 分层、单一近白主按钮、"Agent run/待决策"信息结构 | 纯黑 + 大量 `backdrop-filter` 在窄侧栏吃 GPU 且发糊 |
| **affectUI** | trace / 工具步骤 / 审批卡的信息结构（仅用于"AI 生成属性"一处） | 多数 Pro 付费；黑白极简与纸感冲突 |
| **Prestige UI** | 仅"动效只做 hover/入场"的尺度 | 落地页营销动效对工具无用 |
| **goopUI** | 仅"点阵画布"纹理思路（暗色纸纹备选） | 黏液/粘滞交互与"记录"目标相反 |
| **PlopUI** | 仅"按下 1px 挤压位移"微反馈 | 手写字体 Windows 缺失；贴纸头像与 Inkra 重复且更吵 |

## 三个方向共同的改进点（无论选哪个都要落）

1. 功能图标全部改 inline SVG（现役 `☰ ⚪️ ⚙️ 🃏 📅 🔥 🧠 ⊞ 💾 ⛁ 🗂️ 📋 📅📆⏱` 是"丑"的第一因）。
2. 视图切换只保留底部 dock（删顶部 `.view-modes` 重复入口）。
3. 视图头在 ≤420px 改两行（现状 6 个控件挤一行）。
4. 时间线小时线改**实线发丝**（虚线 + 格线 = 草稿纸感）。
5. 字号从"11px 通杀"改成 10.5/11.5/12.5/14/17 五档。
