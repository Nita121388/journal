# 宽屏模式（宽标签页自动铺满全宽布局）

## Goal

扩展在宽浏览器标签页打开时自动进入宽屏布局，不再锁 960px 居中；主容器放开宽度、时间线多列 lane、月/周历格子加大。窄侧边栏完全保持不变。

## 背景

这个扩展既可作为侧边栏打开，也可点击图标开成宽浏览器标签页（`background.js` 的
`tabs.create(url, sidepanel.html)`）。但 `sidepanel.css` 把 `main` 锁死在
`max-width: 960px; margin: 0 auto`，宽标签页下内容挤在中间、两侧大片空白，
月/周历与时间线都是窄列布局，空间利用率低。

## Requirements

1. **自动检测宽屏**：默认在窗口较宽（视口宽 ≥ ~1100px）时进入宽屏布局；窄窗口
   （侧边栏 / 窄标签页）保持现有单列紧凑布局，行为完全不变。
2. **手动切换按钮**：在右侧视图工具区新增「宽屏模式」切换按钮，支持三态循环：
   `auto（自动跟随窗口）→ on（强制宽屏）→ off（强制窄屏）→ auto`。选择持久化
   到 localStorage，刷新后保留。
3. **宽屏布局表现**：
   - `main` 放开 `max-width`，内容铺满可用宽度。
   - 左侧栏保持约 280px，时间线/日历占用剩余全部空间。
   - 月历、周历格子随宽度加大，卡片摘要显示更完整。
   - 时间线 `schedule-canvas` 天然支持多列 lane（重叠卡片左右排布），宽屏下 lane
     自动变宽、不叠压。
   - 窄屏（<720px，侧边栏场景）逻辑与现有 `@media` 完全一致，宽屏模式不影响。
4. **一致性与回归**：窄侧边栏、手机级宽度下所有现有行为（隐藏侧栏、单列收起）不变。

## Acceptance Criteria

- [ ] 在宽窗口标签页（视口 ≥1100px）打开 `sidepanel.html`，内容铺满全宽、不再
      锁定 960px 居中。
- [ ] 月历/周历格子宽度随容器扩大而变宽，卡片摘要不截断扭曲。
- [ ] 时间线有重叠卡片时左右并排（多 lane），宽屏下卡片宽度合理占满。
- [ ] 视图工具区出现「宽屏模式」按钮，三态循环 `auto→on→off→auto` 正确，且状态
      持久化、刷新后保留。
- [ ] 在窄窗口/侧边栏打开，行为与改动前完全一致（单列、隐藏侧栏等）。
- [ ] 手动按钮能覆盖自动检测（宽窗口强制窄、窄窗口强制宽）。

## Notes

- 纯前端改动：`extension/sidepanel.css` + `extension/sidepanel.html` +
  `extension/sidepanel.js`，不涉及 host / 数据层。
- 宽屏模式沿用现有 `documentElement.dataset.theme` 的做法，改用
  `documentElement.classList` / 预设宽或基于视口 media query 切换。
