# Journal UX 审计报告（第一轮）

> 审计人：Pi agent（资深 PM 视角）· 日期：2026-09-28
> 方法：基于 dev-loop 采集的 **18 张真实渲染截图**（3 宽度 × 亮/暗 × 时间线/周/月，有数据态）+ 布局量化指标 + 源码锚点。每条结论均附证据。
> 截图产物：`dev-loop/out/<ts>/`（`{light,dark}-{timeline,week,month}-{360,400,500}.png`）

## 0. 产品与审计范围

- **产品**：Journal —— Chrome MV3 侧边栏每日日志 + 打卡 + TODO + AI 助手。
- **真实使用环境**：Chrome 侧边栏，宽度约 320–500px（可拖拽，宽度不可程序化设置）。
- **审计基准**：360 / 400 / 500px 三档视口（覆盖侧栏常见宽度），亮暗双主题，日/周/月三视图，有数据态（5 张样例卡片）。

## 1. 关键量化发现（先看这个）

所有 18 种组合中，布局位置恒定：

| 区块 | top 坐标 | 说明 |
|---|---|---|
| sidebar（卡片池+日历+热力图+技能） | y=74 | 4 个次要面板堆叠 |
| timeline-section（主工作区） | y=780 | 800px 视口下几乎完全在折叠线之下 |
| 视口高度 | 800 | — |

**结论：主工作区（日程/日志）在真实侧栏中「几乎永远看不到首屏」，用户每次打开都需要滚动约 780px 才能到达核心工作区。** 这是本产品最高优先级问题。

**根因（源码级）**：`sidepanel.css:130-132` 已有针对窄屏的修复：
```css
@media (max-width: 720px) {
  #board { grid-template-columns: 1fr; }
  #sidebar { display: none; } /* 窄屏隐藏侧栏，简化 */
}
```
但 `sidepanel.css:189` 的 `#sidebar { display: flex; ... }` 与之**特异性相同、位置更靠后**，按 CSS 层叠后者胜 → **媒体查询的 `display:none` 是死代码，从未生效**。所有真实侧栏宽度（<720px）下侧栏都强制显示。这是 P0 缺陷。

## 2. 审计结论（按维度）

### A. 信息架构与布局【P0】
- **A-1 窄屏侧栏隐藏失效（P0）**。证据：`sidepanel.css:130-132` vs `189`；截图 360/400/500 侧栏均显示。影响：所有真实侧栏用户被迫承担「三栏 → 单栏」的拥挤。修复：提高媒体查询规则优先级（如 `#board #sidebar`、或把 `display:none` 移到文件末尾、或给基础规则加 `@media` 内联）。预期收益：单栏后时间线直达首屏，IA 倒置立即缓解。
- **A-2 侧栏承载 4 个次要面板、主工作区被挤（Q0/P0）**。证据：sidebar 占 y74–780 装下卡片池/日历/热力图/技能状态。修复方向：侧栏默认折叠为图标条/抽屉，或将「打卡热力图」「技能状态」移入设置页/可折叠区。修复 A-1 后此问题部分自动缓解。
- **A-3 三栏栅格在侧栏场景不适用**。证据：`sidepanel.css:122` `grid-template-columns: 280px 1fr`。280px 固定列 + 16px gap 意味着时间线在 360px 视口下可用宽不足 64px；截图显示时间线被挤成窄列。修复：侧栏场景默认单栏（配合 A-1）。

### B. 视觉层级与一致性【P1】
- **B-1 卡片池筛选 chips 过载（P1）**。证据：截图见 9 个 chips（全部/待办/未开始/进行中/已完成/纯记录 + 项目/标签）挤占两行；源码 `sidepanel.js:1458` 状态+项目+标签全渲染。影响：视觉噪音、认知负担。修复：默认只显示「全部 + 状态」，项目/标签折叠进「筛选」弹层；chips 数量上限 + 横向滚动。
- **B-2 时间线卡片高度虚高、留白浪费（P1）**。证据：截图「完成 dev-loop 闭环脚本」卡片只有一行标题，下方大片空白。影响：单屏可见卡片数少，信息密度低。修复：卡片高度随内容自适应，设置最小高度；长内容折叠。
- **B-3 图标全为 emoji、跨平台不一致（P1）**。证据：截图/源码中功能图标用 📓⚙️🃏🗂📅🔥🧠⏱⊞💾⛶；`sidepanel.html` 内联。影响：Windows/macOS 渲染风格与字重不同，缺 hover/focus/disabled 态，无视觉系统。修复（设计系统规范中定义）：**功能图标改用统一 SVG 图标集（16/20/24 网格）；emoji 仅用于内容语义（卡片 emoji、氛围）。**
- **B-4 设计 token 渗透不彻底（P2）**。证据：`sidepanel.css` 有 29 个 CSS 变量但仍散落 **79 处硬编码 hex**、8 处 `!important`；`sidepanel.js` 22 处内联 `style.*`。影响：暗色/主题切换不彻底、后续改色易漏。修复：分两步——① 把硬编码 hex 归一到语义 token；② 消除内联 style 改用 class。

### C. 交互流程【P1】
- **C-1 时间线密度低、大量空时段（P1）**。证据：截图时间轴 08:00–13:00 多为空白（仅 1 张 09:00 卡片）。影响：纵向空间浪费，「时间线」信息稀薄。修复方向：① 空时段折叠/压缩行高；② 无卡片时以「+ 在此添加」弱提示引导；③ 增加「当前时刻」高亮（已有「现在」标记，可强化）。
- **C-2 「＋ 新卡片」反馈不明确（P2，观测）**。证据：smoke 场景点击 `#btn-new-card` 后无弹窗、无新卡片（此前可行性验证观测）。需在审计交互时确认落点（可能打开模板选择态）。修复：点击后在时间线上高亮新卡片落点或给出 toast 反馈。
- **C-3 视图模式/宽屏/范围切换图标可发现性低（P2）**。证据：截图工具条 `⛶ / 08–22 / 📅📆⏱` 全为符号，缺文字标签（仅 title）。修复：图标 + 短标签，active 态明确。

### D. 状态设计（空/加载/错误/成功）【P1】
- **D-1 空状态文案缺行动指引（P1）**。证据：`sidepanel.js:1542` 空列表仅显示「没有符合条件的卡片」。修复：区分「无卡片」vs「筛选无结果」，后者提供「清除筛选」行动按钮。
- **D-2 空状态与计数 badge 语义重复（P2）**。证据：截图「卡片池 5」与空态并存时易混淆（无卡片时计数 0 + 空文案）。
- **D-3 加载态未系统化（P2）**。证据：未见骨架屏；host 离线仅顶部 banner。修复：>300ms 显示骨架，>1s 显示进度。

### E. 可访问性【P1】
- **E-1 缺 `prefers-reduced-motion`（P1）**。证据：全仓 `prefers-reduced-motion` 出现 **0 次**。影响：动效敏感/前庭障碍用户无法降级；现有动效（弹窗入场、hover）全无降级。修复：`@media (prefers-reduced-motion: reduce)` 归零动画。
- **E-2 缺焦点管理/roving tabindex（P1）**。证据：`tabindex` 出现 **0 次**、`sr-only` 0 次。影响：日历网格、卡片池列表键盘可达性弱；无 tabindex 排序时 Tab 顺序=DOM 顺序。修复：可交互网格加 roving tabindex + 方向键。
- **E-3 emoji 图标缺可访问名（P1，联动 B-3）**。证据：`sidepanel.html` 中 ⚙️/🗂 等按钮部分有 `aria-label`，但内联 emoji 图标需逐一核验；SVG 化后统一 `aria-hidden` + `aria-label`。
- **E-4 暗色 today 单元格对比度待修（P2）**。证据：暗色截图日历「28」为深色字压中等绿底，层级偏低。修复：暗色下 today 用高对比组合（白字 + 深绿 / 提亮绿 + 深字），实测对比 ≥4.5:1。

### F. 可发现性【P2】
- **F-1 技能状态面板默认收起但信息重要（P2）**。证据：截图「AI Skill 状态」默认 `▾` 收起。新用户不知其存在。修复：首次使用引导或空态提示。
- **F-2 命名视图/保存视图可发现性低（P2）**。证据：`💾` 保存视图、`⊞` 布局切换为纯符号（截图左上）。

### G. 暗色与主题【P1】
- **G-1 暗色仅 JS 切换、无系统偏好兜底（P1）**。证据：`sidepanel.js:2448-2450` 依赖 settings + `matchMedia`，但 `sidepanel.css` **无 `@media (prefers-color-scheme)`**。影响：系统深色但设置=auto 时需 JS 正确初始化；且 CSS 层面无原生兜底。修复：CSS 增加 `prefers-color-scheme` 作为默认，`[data-theme]` 显式覆盖。
- **G-2 暗色整体一致（观察为正面）**。证据：暗色三视图配色一致，无明显破版。

### H. 响应式/多宽度【P1】
- **H-1 唯一媒体查询 720px 且失效（P1，联动 A-1）**。证据：`sidepanel.css` 仅 `@media (max-width:720px)` 一处且被层叠覆盖。修复：建立 320/360/440/560 断点体系并确保生效。
