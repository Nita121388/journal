# 阶段B 统一卡片池 UI

## Goal

把旧「卡片池 + 待办」两区合并为**唯一统一卡片池**，支持 schema 驱动筛选、多色卡片、列表/卡片布局、紧凑/舒展/全屏尺幅与命名视图。UI 不再区分文本与待办。

## Requirements

- **R1 合并为单一主视图**：删除旧「📝 待办」区块，只保留统一卡片池；UI 不再出现「类型」「待办区」心智。
- **R2 schema 驱动筛选器**：状态(none/todo/doing/done) / 优先级 / 项目 / 标签 / 有无日期 / 自定义属性 / 只读元数据(修改时间、修改者、设备)。「待办」= 预设 `status∈{todo,doing}`，与其他筛选 AND 叠加。
- **R3 多色卡片**：按状态/属性着色，露出 emoji、标题、状态、进度、关键属性。
- **R4 布局**：卡片视图（多色网格）/ 列表视图（密集行，可显隐列、排序）。
- **R5 尺幅**：紧凑（侧栏默认）/ 舒展（宽屏占更多宽）/ 全屏（覆盖层大卡片池）；复用现有宽屏三态。
- **R6 命名视图**：当前 (布局+尺幅+列+排序+筛选) 可存成命名视图并切换（`meta['savedViews']`）。

## Acceptance Criteria

- [ ] 卡片池为唯一主视图；旧待办区移除；无「类型」概念显示。
- [ ] 筛选「待办」显示所有 `todo/doing` 卡；与标签/属性筛选 AND 叠加。
- [ ] 自定义属性可作筛选维度；只读元数据列（修改时间/修改者/设备）可显示不可编辑。
- [ ] 卡片按状态/属性着色，露出 emoji/标题/状态/进度/关键属性。
- [ ] 卡片/列表布局可切换；列表可显隐列、排序。
- [ ] 紧凑/舒展/全屏三档可切换。
- [ ] 命名视图可保存/切换/删除。
- [ ] `npx eslint extension/` 0 errors；`npx vitest run --coverage` 达标。

## Out of Scope

- 编辑器改动（阶段 C）、模板（阶段 D）。
- 属性/模板/视图跨端同步（本机）。
