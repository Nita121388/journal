## 1. 方案 — 新建模板（模板构建器）

### 1.1 修复 F1（必做，功能性）
把「＋ 添加属性」从隐藏面板**移出**，成为「额外属性」组标题行的**常驻按钮**；点击它才切换候选列表（`#tpl-add-list`）的显隐。候选列表与触发按钮分离，避免自锁。

### 1.2 窄栏重排（对齐设计系统）
- **头部**：emoji 瓦片 + 模板名称输入（占满剩余宽度，✕ 右上）。标题「保存为模板」降级为输入框上方小标签或占位符。
- **必备属性组**：默认折叠为一行摘要「✓ 标题 · 内容 · 标签（自动包含）」，可展开编辑默认值 —— 降低默认占高（现 3 行恒显）。
- **额外属性组**：组标题行右侧常驻「＋ 添加属性」；候选项改为**纵向列表**（每项：图标 + 名称 + 类型小标签），360 下更易点、不横向换行。
- **底部**：`保存模板`（主）/ `取消`（次）并排；`从当前卡预填` 收进 `⋯` 次级菜单或标题行。
- 复用设计系统 token（面板底 `--color-surface`、圆角 `--r-lg`、焦点环 `--color-focus`）。

## 2. 方案 — 新建属性表单

### 2.1 字段布局（修 F3）
- 由「多 label inline 并排」改为**纵向堆叠**：每个字段 label 在上、控件在下、占满宽度。窄栏 360 下每字段独占一行，消除挤压。
- 宽屏（≥480px）时可选两列（显示名+图标 一行、类型+属性键 一行），用 flex-wrap 自适应。

### 2.2 字段细节
- **显示名/名称**：文本输入，保留。
- **图标**：改为 emoji 快捷选择（点开小网格面板，从现有 emoji 库选），不再纯手输。
- **类型**：全宽 select（文本/数字/选择/多选/日期/时间/勾选）。
- **属性键**：文本输入（英文 key），可由显示名自动生成建议。
- **选项**：仅当类型=选择/多选时显示（保留现有动态显隐逻辑）。
- **按钮**：`加入模板/添加`（主，全宽或右对齐）、`取消`（次，文本按钮）。

## 3. 变更边界

- 主要改 `extension/sidepanel.css`（`.tpl-builder*` `.prop-form*` 窄栏布局）+ `extension/sidepanel.js`（F1 逻辑：添加按钮移出隐藏面板；图标选择器可选）。
- 少量改 `sidepanel.html`（头部结构、图标字段换成按钮触发）。
- 不改卡片字段体系、不改保存为模板的业务逻辑。
- 用 dev-loop 回归 + 截图核验。

## 4. 验收

- [ ] F1：模板构建器能正常添加属性（按钮可点、候选可选、新建表单可达）。
- [ ] F3：360px 属性表单无挤压（纵向堆叠），无横向滚动。
- [ ] 新建/编辑属性全流程可用；亮暗主题一致。
- [ ] dev-loop 回归全绿、0 console error。
