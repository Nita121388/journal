# PRD: 时间线卡片系统

## Goal

将 Journal 的日志编辑区从"每天一个文本块"升级为**纵向时间线卡片系统**。卡片是应用的核心原子单元——一个带时间戳的文本单元，统一承载日志（text）、待办（task）、灵感（idea）三种语义。新增卡片池（待命状态），支持拖拽/点击安排到具体日期与时间，日历与热力图按卡片数量显示强度。

## Background / 现状

- 当前右侧是单个 `<textarea>`，每天一条 markdown 文本
- 数据模型：`journals[dayKey] = { content, createdAt, updatedAt }`（每天 1 条）
- 日历格子只显示"有无"（0/1），热力图同样只显示 0/1
- TODO 与日志是两个割裂的模块

## 核心洞察

> 卡片 = 一个在某个时间点产生的想法/行动/记录。日志、待办、备忘本质都是卡片，不应割裂存储。

## Requirements

### 数据模型（统一卡片模型）

```js
{
  id: "c_1694982710000",      // 时间戳 ID
  content: "回复老王邮件",      // 文本内容
  type: "text" | "task" | "idea",
  done: false,                // 仅 task 类型有效
  assignedDate: "2026-09-18" | null,  // null = 在卡片池
  time: "09:31" | null,       // HH:MM 精确到分钟；null = 未安排时间
  createdAt: "2026-09-18T09:31:00.000Z",
  updatedAt: "2026-09-18T14:20:00.000Z",
}
```

存储结构：`cards: Card[]` 扁平数组（取代 journals / todos）。

### 右侧：纵向时间线视图

- 选择某一天后，右侧显示该天的**纵向时间线**
- 时间轴刻度：每 30 分钟一个刻度（视口高度 < 600px 时每 1 小时）
- 有卡片的时刻显示实心圆 ●，空时刻显示空心圆 ○
- **点击空时间点** → 弹出迷你创建面板，在该时间点新建卡片
- **同时间（≤5 分钟内）卡片左右并列**（最多 2 列，超过堆叠）
- 点击卡片 → 编辑（边框变 accent 色，点击外部自动保存）
- 卡片显示时间、类型图标、字数；task 卡片显示完成勾选
- 底部按钮"＋ 在当前时间新建卡片"

### 左侧：卡片池

- 新增"卡片池"面板：未安排（assignedDate=null）的卡片列表
- 点击"＋ 新卡片" → 在池中创建空卡片，立即编辑
- 卡片池卡片可点击 → 安排到某天（弹出日期选择）
- 卡片池卡片可拖拽到日历/热力图某天 → 安排到那天
- 空池显示"没有未安排的卡片 📋"

### 日历：按卡片数量显示

- 格子背景色随当天卡片总数渐变（0→透明，1→浅绿，5+→主色绿）
- 格子内显示当天卡片类型图标摘要（📝/☑️/💡 + 数量）

### 热力图：按卡片数量显示强度

- 颜色分 6 档（0,1,2,3,4,5+），与卡片数量映射
- hover tooltip：`2026-09-18 · 3 张卡片 (2 📝 1 ☑️)`
- 点击热力图某天 → 切换到那天的时间线

### 向后兼容迁移

- 旧 `journals[dayKey]`（string 或 {content,...}）→ 转为 1 张 `text` 卡片，`assignedDate=dayKey`，`time=null`（显示在时间线当日，置于顶部）
- 旧 `todos[]` → 转为 `task` 卡片，`assignedDate=due ?? null`
- host 文件结构升级为 `cards`，扩展侧首次读取自动迁移并写回

### 验收标准

1. 右侧时间线按时间顺序渲染当天卡片，时间刻度可见
2. 点击空时间点可创建卡片，卡片出现在该时刻
3. 同时间卡片并列显示
4. 卡片池可创建/编辑/安排卡片
5. 日历格子按卡片数显示颜色与图标
6. 热力图按卡片数分档着色，hover 显示 tooltip
7. 旧数据迁移后内容不丢失
8. 语法检查通过，host API 手动测试通过

## Non-Goals

- 卡片拖拽改时间（V3 再做）
- 卡片删除确认弹窗
- Markdown 预览
- 卡片搜索
- 多用户协作
