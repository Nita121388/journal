# 模板构建器属性行改造：扁平列表 + Notion 式添加 + 右键菜单 + 本地规则推断

## Goal

把模板构建器（sidepanel 弹窗）的属性编辑从「分组盒子 + 弹窗表单 + 候选面板」改成 Notion 风格：
属性列表扁平化、添加一行式直接新增、行内直接编辑（图标点击切换 / 属性名双击改 / 属性值编辑 / 右键菜单），
并在新建属性时**按属性名自动推断** key / 图标 / 类型 / 默认值 / 选项，用户可再手动修改。

> 本轮只做**本地规则推断**（零网络、零 key），LLM 增强（host 代理）拆为后续独立任务。

## Requirements

1. **扁平化列表**：去掉「✓ 必备」分组的边框盒子与折叠标题；去掉「额外属性（可选 · 可增删改排序）」标题。所有属性行（含内置 title/content/tags）合并为单一扁平列表，行高、行视觉统一。
2. **Notion 式添加**：原虚线「＋ 添加属性」按钮改为与属性行同高的一行式添加行（hover 高亮）。点击后**直接新增一行**，不进弹窗、不弹候选面板。新增行自动进入编辑态。
3. **行内直接编辑**（每一行）：
   - 图标：点击弹出 emoji 选择器切换（复用现有 picker）
   - 属性名：双击进入内联编辑，回车确认 / 失焦确认 / Esc 取消
   - 属性值：按属性类型的默认值编辑器（复用 buildTplDefaultEditor 逻辑）
4. **右键菜单**（属性行 contextmenu）：
   - 编辑属性（改显示名 / 图标）
   - 修改属性类型（文本/数字/选择/多选/日期/时间/勾选/起止时间/标签/文本域）；切换类型后默认值重置为该类型空值
   - 上移 / 下移（保留拖拽排序作为主方式，菜单为补充）
   - 从模板移除（仅可选属性；内置三件套不显示该选项）
5. **本地规则推断**：新建属性时输入属性名，即时推断：
   - key：属性名本身（隐形、自动去重加后缀），改名只改显示名、key 不变
   - 图标：复用 `searchEmojis(name)`（emoji 库含中文关键词），命不中给默认
   - 类型 + 选项：关键词规则表（日期/起止/数量/是否/状态/优先级/负责人/标签/备注…），命不中默认 text
   - 默认值：按推断类型给空值（与 defaultTplValue 一致）
   - 推断是「推荐」，用户可改且用户修改优先级更高
6. **内置三件套**（title/content/tags）：图标、显示名可改，**类型锁定**（title=text、content=textarea、tags=tags），不可删除。

## Constraints

- 不引新依赖；纯前端，改动集中在 `extension/sidepanel.js / .html / .css`
- 不破坏卡片数据与模板数据格式（key 语义不变：改名不改 key）
- 属性库（`meta['propertyLibrary']`）与模板 fields 的既有读写路径不动
- 遵守 component-guidelines：DOM 构建用 createElement/textContent，不用 innerHTML 拼用户内容
- 保留拖拽排序（tpl-extra-row 现有机制）
- 保留从当前卡预填、保存模板、取消等构建器外围行为

## Acceptance Criteria

- [ ] 模板构建器中不再出现「✓ 必备」分组边框/标题与「额外属性」组标题；所有属性为同一扁平列表
- [ ] 添加行与属性行同高；点击直接新增一行并进入编辑态（光标落在属性名），无需弹窗/候选面板
- [ ] 行内：点图标弹出 emoji picker 可换图标；双击属性名可内联改名（回车/失焦确认、Esc 取消）；属性值按类型可编辑
- [ ] 右键菜单包含：编辑属性 / 修改属性类型 / 上移 / 下移 / 移除（内置三件套无「移除」，且「修改类型」对其不可用）
- [ ] 切换类型后默认值重置为该类型空值，模板 fields 保存的类型为最新类型
- [ ] 新建属性输入「重要度」→ 自动推断 icon=⭐️、type=select、options=[高,中,低]、key=重要度；输入「截止日期」→ type=date、icon=🗓️；输入「备注」→ type=textarea；输入「xxx 未知词」→ 兜底 text
- [ ] 同名属性自动去重（key 加后缀），改名不改 key，保存后属性库/模板字段 key 不变
- [ ] 内置三件套图标/显示名可改、类型不可改、不可移除
- [ ] 无回归：模板保存/编辑、预填、拖拽排序、卡片编辑器属性行仍正常
