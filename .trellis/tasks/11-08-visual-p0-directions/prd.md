# P0 方向样张：三个视觉方向的可点击静态稿

## 背景

主任务 `11-08-visual-redesign-paper-desk` 决定重构视觉，但「好看」无法用文字评审，
必须在真实数据、真实宽度（320/400/500）、真实主题（亮/暗）下目视比较。
本任务只产样张，**不改 `extension/` 任何代码**。

## 需求

| # | 需求 |
|---|---|
| R1 | 三个方向各自一个自包含 HTML（无外链、无构建）：`a-paper-desk` / `b-quiet-desk` / `c-handdrawn-desk` |
| R2 | 三者内容完全相同，仅视觉语言不同，便于同屏比较 |
| R3 | 内容取自本项目真实数据：`11月8日 周日 · 1 条记录`、三张真实卡片（闭环脚本 / 灵感产品感 / 卡片编辑器）、当前时间 16:55 |
| R4 | 同一屏必须包含：header（标题+日期+3 图标按钮）、两行视图头、时间线（含小时轨与当前时间线）、底部 dock、以及至少 1 个省钱级细节（vignette/tape/纹理） |
| R5 | 支持 `?theme=dark`；三方向都必须是完整暗色方案，不是把浅色反相 |
| R6 | `index.html` 目录页：并排 iframe 预览 + 每方向一段「抄了什么 / 牺牲了什么」说明 |
| R7 | 截图存档 `docs/design/directions/shots/`：3 方向 × 320/400 × light/dark，共 12 张 |

## 非目标

- 不做交互（点击/拖拽/滚动锚定），只做静态视觉。
- 不追求像素级对齐现役 DOM；样张是「目标态」，不是「可运行代码」。
- 不引入字体文件、不引外链资源（`file://` 直接打开即可看）。

## 三个方向的立场

| 方向 | 立场 | 主要参考 |
|---|---|---|
| A `paper-desk` | 暖纸底 + 墨线分隔 + 墨块主按钮；绿只作数据色 | Inkra（纸面）、BoardUI（结构） |
| B `quiet-desk` | 纯白/石板灰 + 蓝主色 + 大圆角 + 软投影 | BoardUI（字面复刻）+ HeroUI |
| C `handdrawn-desk` | 奶油纸 + 抖动墨边 + 楷体标题 + 印章红 | Looseleaf + PlopUI + Inkra |

## 验收标准

1. 三个 HTML 在 Chrome / `file://` 下直接打开无 console error、无外链请求。
2. 320 / 400 / 500 三宽度下：无横向滚动条、无文本截断到不可读、dock 不遮挡最后一张卡。
3. 暗色：正文对比度 ≥4.5:1（纸底与卡底各测一次），主按钮与底对比 ≥4.5:1。
4. 12 张截图命名规范：`<direction>-<width>-<theme>.png`。
5. 用户选定一个方向后，在本任务 `notes` 记录：方向 + 主色 + 需要调整的点（不超过 5 条）。
