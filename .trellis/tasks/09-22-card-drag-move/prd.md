# 卡片支持拖拽移动位置

## Goal
时间线（日程画布）上的卡片支持拖动主体纵向移动，改变开始时间。时长保持不变，移动按 15 分钟网格吸附，仅限同一天内，拖放后持久化。

## Requirements
- 拖动有开始时间的卡片主体（header/body 区域）可纵向移动位置，底部 resize 手柄仍只调时长。
- 拖动过程中实时预览新位置（顶部随指针移动、时间标签实时更新），15 分钟吸附。
- 移动保持时长不变：`endTime = newStartTime + 原时长`；边界钳制到画布范围 08:00–22:30（移动后结束时间不得越过 22:30）。
- 拖放完成后持久化 `startTime` / `time` / `endTime`（沿用 `updateCardEntry` 写 host + 缓存）。
- 拖拽结束要抑制一次点击事件，避免拖完误打开编辑器（复用现有 `suppressClick` 模式）。
- 拖动不触发 footer 按钮（完成/类型/删除）与 resize 手柄的交互。
- 拖放后重新布局 lane（重叠卡片横向并排），调用现有 `refreshAll()` 全量重渲染。
- 全天卡片（无开始时间）不在本次拖动范围内；不做跨日期拖动。
- **短卡片内容可见性**：时长 ≤ 30 分钟的短卡片（30px 高）必须在不动画/不交互时也能看到内容，不能因高度裁剪而只看到 header。
- **短卡片紧凑布局**：15–30 分钟卡片收缩底部 padding、折叠 footer，使 header + 首行正文在槽位高度内可见。
- **短卡片悬停展开**：hover 此类卡片时抬升 z-index、高度撑开以显示完整内容与 footer；移出后恢复紧凑态。悬停展开在拖拽中（`.is-dragging`）不触发，避免拖动时卡片涨高。

## Acceptance Criteria
- [ ] 拖动卡片主体可在画布内纵向移动，位置随 15 分钟网格吸附。
- [ ] 移动后时长保持不变，`startTime`/`time`/`endTime` 正确持久化。
- [ ] 移动后结束时间不超过 22:30，开始时间不低于 08:00。
- [ ] 拖放后卡片落在新位置且与重叠卡片正确并排（lane 重排）。
- [ ] 拖拽后不误触发点击编辑。
- [ ] resize 手柄、footer 按钮、点击编辑、当前时间 marker、卡片池功能不回归。
- [ ] 全天卡片、跨日期拖动不在范围内，行为不改变。
- [ ] JavaScript 语法检查通过（`npx eslint extension/` 0 errors）。

## Out of Scope
- 拖动全天卡片赋予时间。
- 跨日期拖动。
- 后端 API 或存储协议改造。
