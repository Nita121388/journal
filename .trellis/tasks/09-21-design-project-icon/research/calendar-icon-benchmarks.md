# 日历图标对标调研

## 调研结论

本次重点参考四类成熟方向：Twemoji、Google Calendar/Material、Apple Calendar、Notion Calendar。外部搜索后端不可用，因此不记录未经核验的具体版本截图；以下是基于公开产品视觉语言与可复用图标结构的设计归纳。

## 参考方向

### 1. Twemoji：情绪与识别度

- 使用大色块、圆润轮廓和有限颜色。
- 细节不是靠大量线条，而是靠顶部结构、阴影/高光和轮廓层次表达。
- 小尺寸下仍保留一个明确主体，不堆叠文字或复杂日期格。
- 适合本项目的部分：圆角、友好、适度拟人化；不直接照搬其具体形状或资产。

### 2. Google Calendar / Material：信息结构

- 日历最关键的识别元素是“顶部装订环/挂钩 + 独立纸面”。
- 主体通常使用规则几何形状，边界清晰，缩小后仍能读出日历。
- 适合本项目的部分：把日历分成“顶部栏、纸面、装订点”三层，避免画成普通方卡片。

### 3. Apple Calendar：时间语义

- 通过顶部日期/星期和底部日历纸面表达“日期”，而非依赖完整网格。
- 视觉上克制，留白较多，轮廓优先。
- 适合本项目的部分：不塞 7×5 日期网格；只保留 2–3 个有节奏的标记或抽象日期点。

### 4. Notion Calendar / 现代生产力工具：专业与生活感

- 常用极简几何、低数量颜色与轻微品牌色点缀。
- 重点是“记录/计划”的抽象语义，而不是模拟真实纸质日历。
- 适合本项目的部分：绿色主体配中性纸面，笔作为第二识别元素；笔不遮住日历顶部结构。

## 设计建议

1. **日历主体不要画成单一绿色方块**：采用三层结构：浅纸面、绿色顶部栏、两个圆角装订环。
2. **避免完整日期网格**：16/32px 下会变成噪点；使用 3 个圆点/短线表示记录内容即可。
3. **笔要形成清晰斜向动势**：约 -35°，从右下指向左上；笔尖落在纸面区域，表达“正在记录”。
4. **层级顺序**：日历为主、笔为辅。笔覆盖右下角约 20–25%，不能遮挡顶部装订结构。
5. **颜色**：成长绿 `#5BB974` 作为顶部栏/主体强调色；纸面使用暖白；笔使用深墨绿或蓝灰，橡皮/尾部使用低饱和珊瑚色作为唯一暖色点缀。
6. **小尺寸策略**：SVG 源保持完整结构；PNG 在 16/32px 只保留主体轮廓、顶部栏、装订点和粗笔形，不放日期文字。
7. **轮廓**：使用深色低对比描边或深绿阴影，避免纯黑描边造成廉价贴纸感。

## 推荐最终构图

圆角方形日历纸面（暖白）+ 成长绿顶部栏 + 两个圆角装订环 + 纸面内三枚短记录线/圆点 + 一支深墨绿斜笔，笔尾用低饱和珊瑚色。整体采用扁平色块、少量柔和阴影，不使用渐变和细密网格。
