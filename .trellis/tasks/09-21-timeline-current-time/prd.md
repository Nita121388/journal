# 添加今日当前时间刻度

## Goal

在 Journal 今日时间线中显示当前时间刻度，让用户快速定位现在处于哪个时间段。

## Requirements

- 仅在查看今天时显示当前时间标记；历史日期和未来日期不显示。
- 当前标记显示到分钟，例如“现在 14:37”。
- 标记位于当前半小时时间槽内，不新增破坏既有 30 分钟节奏的时间槽。
- 使用主题绿色横线/标记与普通时间轴区分，且不遮挡卡片内容。
- 每分钟自动更新当前时间标记。
- 不修改存储、数据模型、后端或卡片编辑逻辑。

## Acceptance Criteria

- [ ] 今天的时间线显示当前时间 marker，包含“现在”和 HH:mm。
- [ ] 查看非今天日期时 marker 不显示。
- [ ] marker 每分钟更新，不需要手动刷新页面。
- [ ] marker 不影响现有时间槽、卡片点击和滚动。
- [ ] JavaScript 语法检查通过，相关 CSS/DOM 结构清晰。

## Design Notes

- 采用 MVP：marker 放在当前半小时槽的顶部/显著位置，不按槽内像素比例定位，避免卡片高度变化导致抖动。
- 当前时间早于 08:00 或晚于 22:30 时不显示 marker，避免脱离当前时间线范围。
